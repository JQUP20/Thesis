# 数值结果

## 1. 模型一：广义 Ising 模型（有限温度纯化）

### 哈密顿量

$$H_\text{Ising} = -J_x \sum_i \sigma_i^x \sigma_{i+1}^x - h_z \sum_i \sigma_i^z - J_z \sum_i \sigma_i^z \sigma_{i+1}^z$$

**参数**：$J_x = h_z = 1$，$J_z = 0.1$（量子相变点附近）

**系统大小**：$L = 50$ 格点，开边界条件

### 测量量

**半链纠缠熵**（von Neumann 熵，作为键维度需求的代理）：

$$S_\text{vN}(L/2) = -\mathrm{Tr}[\rho_{L/2} \log \rho_{L/2}]$$

### 结果（图1示意）

```
纠缠熵 S vs 逆温度 β

  S |
    |  ●● TFD（无解纠缠）
    | ●  ●
    |●    ●
    |      ●●
    |        ●● ○ 解纠缠 k=2
    |           ○○○
    |              ○○ △ 解纠缠 k=4
    |                △△△△△
    |---------------------> β (温度降低)
    0                 β_max
```

**关键观察**：
- 低温（大 $\beta$）时，解纠缠效果最显著
- $k=4$ 比 $k=2$ 进一步降低纠缠，但差距在低温时也在缩小
- 高温（小 $\beta$）时，解纠缠效果有限（接近随机态，难以解纠缠）

### 定量结果（低温区，$\beta \approx 5$）

| 方法 | 半链 $S_\text{vN}$ | 所需 $\chi$ |
|------|-------------------|-------------|
| TFD（无解纠缠） | $\sim 4.5$ | $\sim 100$ |
| 解纠缠 $k=2$ | $\sim 3.0$ | $\sim 20$ |
| 解纠缠 $k=4$ | $\sim 2.5$ | $\sim 10$ |

纠缠熵减少 $\sim 1.5$–$2$，对应键维度降低约一个数量级。

## 2. 模型一（续）：可达最大温度 $\beta_\text{max}$

**问题**：在固定键维度 $\chi$ 下，能精确模拟到的最低温度是多少？

**结果**：

```
β_max vs χ（固定精度 ε）

β_max |          ○ 解纠缠 k=4
      |      ○
      |  ○
      |●    ● TFD（无解纠缠）
      |  ●
      |-----> χ
      4  8  16  32
```

- 解纠缠后，同样的 $\chi$ 可以到达更低温度（更大 $\beta_\text{max}$）
- 解纠缠使**有效温度范围扩展约 2 倍**

## 3. 模型二：Heisenberg 模型（实时演化/淬火动力学）

### 哈密顿量

$$H_\text{Heis} = J \sum_i \vec{S}_i \cdot \vec{S}_{i+1}$$

**初态**：无穷温度纯化 $|\Psi(t=0)\rangle = |\beta=0\rangle$（最大纠缠态）

**演化**：实时演化 $|\Psi(t)\rangle = e^{-iHt} \otimes \mathbf{1}_\text{anc} |\Psi(0)\rangle$

### 纠缠增长的问题

无解纠缠时，实时演化中纠缠线性增长：

$$S(t) \sim v_E \cdot t$$

其中 $v_E$ 是纠缠增长速率（由 Lieb-Robinson 速度决定）。

这导致 MPS 键维度指数增长，限制可模拟时间。

### 实时解纠缠策略

在每步实时演化后，施加解纠缠器：

```
|Ψ(t + δt)⟩ = U_disent(t+δt) · [e^{-iHδt} ⊗ 1] · |Ψ(t)⟩
```

其中 $U_\text{disent}(t)$ 在每时刻重新优化。

### 结果（图示意）

```
纠缠熵 S vs 时间 t

  S |       ● 无解纠缠（线性增长）
    |     ●
    |   ●
    | ●
    |● ○ 解纠缠（增长放缓）
    |○○○
    |○  ○○○○
    |       ○○○
    |-----------> t
    0   1   2   3
```

**关键观察**：
- 解纠缠后纠缠增长明显放缓（但不能完全阻止）
- 可模拟时间延长约 $2$–$3$ 倍（在同等 $\chi$ 下）
- 长时间后，解纠缠效果趋于饱和（系统纠缠趋于体积律，难以分解）

## 4. 为何纯化无法被完全解纠缠？

**物理直觉**：

1. **热关联不可消除**：有限温度系统中，物理格点之间存在真实的热关联，
   对应纠缠无法通过辅助空间操作消除。

2. **体积律极限**：对于随机（高温）态，纠缠满足体积律 $S \sim L$，
   无法通过局部酉变换降至面积律。

3. **$\beta \to \infty$ 例外**：零温时，态为基态（纯态），
   纯化完全等价于基态本身，辅助空间完全解耦，$S_\text{phys-anc} = 0$。

**数学界**：对于一维量子系统，存在下界：

$$S_\text{min} \geq S_\text{phys-phys}(\rho) \quad (\text{量子互信息下界})$$

其中 $S_\text{phys-phys}$ 是物理子系统之间的纠缠，不受 $U_\text{anc}$ 影响。
