# 解纠缠算法（Disentangler Algorithm）

## 1. 核心思想

给定纯化 $|\Psi\rangle$，所有等价纯化形如：

$$|\Psi_U\rangle = (\mathbf{1}_\text{phys} \otimes U_\text{anc})|\Psi\rangle$$

**目标**：找到最优 $U_\text{anc}^*$，使得总纠缠最小：

$$U_\text{anc}^* = \arg\min_{U_\text{anc}} \sum_{\text{bonds } \ell} S_2^{(\ell)}(|\Psi_U\rangle)$$

其中对所有 MPS 键（bonds）上的第二 Rényi 熵求和。

---

## 2. 全局幺正的局部分解

全局酉算子 $U_\text{anc}$ 作用在整个辅助空间，参数空间巨大。
**关键简化**：将 $U_\text{anc}$ 分解为**两体门**的乘积（解纠缠器网络）：

```
辅助链: a_1 - a_2 - a_3 - a_4 - ... - a_L
              |         |
            U_{12}    U_{34}      (第一层：偶数对)
          |         |
        U_{23}    U_{45}          (第二层：奇数对)
              |         |
            U_{12}    U_{34}      (第三层：再次偶数对，循环)
```

每个 $U_{i,i+1}$ 是 $d^2 \times d^2$ 的幺正矩阵（作用于辅助格点 $a_i, a_{i+1}$）。

---

## 3. 单步优化：最小化两格点 Rényi 熵

### 问题设置

固定所有其他门，优化单个两体门 $U_{i,i+1}$。

对键 $\ell$（位于格点 $i$ 和 $i+1$ 之间）的第二 Rényi 熵：

$$S_2^{(\ell)} = -\log \mathrm{Tr}_A\, \rho_A^2$$

等价于最小化 $\mathrm{Tr}\,\rho_A^2$（$S_2$ 的单调减函数为 $\mathrm{Tr}\,\rho_A^2$ 增大）。

### 梯度计算

$$\mathrm{Tr}\,\rho_A^2 = \langle\Psi_U|\langle\Psi_U| \text{SWAP}_A |\Psi_U\rangle|\Psi_U\rangle$$

其中 SWAP$_A$ 是在子系统 $A$ 上交换两个副本的算符。

对 $U_{i,i+1}$ 的梯度（使用 Wirtinger 微积分）：

$$\frac{\partial \mathrm{Tr}\,\rho_A^2}{\partial U_{i,i+1}^*} = M_{i,i+1}$$

其中 $M_{i,i+1}$ 是通过在 MPS 上收缩张量网络得到的有效矩阵。

### 极坐标分解更新（Polar decomposition）

最优 $U_{i,i+1}$ 满足：

$$U_{i,i+1}^* = V W^\dagger, \qquad M_{i,i+1} = V \Sigma W^\dagger \text{（SVD）}$$

即 $U_\text{new} = V W^\dagger$（$M$ 的"极坐标"）。

---

## 4. 完整算法流程

```
输入：纯化 MPS |Ψ⟩（例如 TFD 态）
输出：解纠缠后的 MPS |Ψ_U⟩，以及解纠缠器 U_disent

重复直到收敛：
  从左到右扫描辅助链：
    对每对 (a_i, a_{i+1})：
      1. 计算有效矩阵 M_{i,i+1}（收缩 MPS 网络）
      2. 对 M 做 SVD：M = V Σ W†
      3. 更新：U_{i,i+1} ← V W†
      4. 将 U_{i,i+1} 作用到 |Ψ⟩ 的辅助链上
      5. 重新规范化（renormalize）MPS
  从右到左扫描（DMRG 两方向扫描）

  计算总第二 Rényi 熵 S_total = Σ_ℓ S_2^(ℓ)
  如果 |ΔS_total| < 阈值：停止
```

---

## 5. 解纠缠器的范围（Range）

**参数**：解纠缠器最大作用范围为 $k$ 个格点（$k$-site disentangler）

- **$k=1$**：单格点幺正（仅局部旋转），效果有限
- **$k=2$**：两体门（CNOT 类），标准选择
- **$k=4$**：四体门，可捕获更长程关联，但计算代价更高

文中展示了 $k=2$ 和 $k=4$ 的比较，更大的 $k$ 一般给出更小的纠缠。

---

## 6. 与 MERA 的联系

本文的解纠缠器结构与**多尺度纠缠重整化拟设（MERA）**中的解纠缠器高度相似：

```
MERA 中：在每层粗粒化（coarse-graining）前先解纠缠
本文中：在辅助链上解纠缠，不改变物理自由度
```

区别在于：
- MERA 的解纠缠器作用于**物理格点**，改变基态波函数
- 本文的解纠缠器作用于**辅助格点**，不改变物理密度矩阵 $\rho$

---

## 7. 计算复杂度分析

| 步骤 | 复杂度 |
|------|--------|
| 每次两体门优化 | $\mathcal{O}(\chi^3 d^4)$ |
| 每次扫描（$L$ 对格点） | $\mathcal{O}(L \chi^3 d^4)$ |
| 收敛所需扫描次数 | $\mathcal{O}(N_\text{iter})$（通常 10-100） |
| 与标准 MPS 虚时演化对比 | 额外开销，但 $\chi$ 可以大幅减小 |

**净效益**：解纠缠使 $\chi$ 减小，从而使后续演化或测量的总代价降低。

---

## 8. 直觉理解

可以将解纠缠器类比为**量子纠错码的解码器**：

- 编码：虚时演化在物理和辅助格点之间建立纠缠
- 解码：解纠缠器找到最优的"基变换"，将辅助自由度中的"冗余纠缠"集中消除

在低温时，系统的热态接近基态，辅助空间几乎不需要，
因此解纠缠可以几乎完全分离辅助和物理自由度。
